# Playbooks

One file per job. Each is a short list of steps with an owner sentence at the top and a **Reply** line at the bottom. Paths in the steps are relative to the skill folder.

Copy the matching playbook's steps into your todo list as written, or keep the list in your reply when there is no todo tool. Work them in order. A step that does not apply keeps its line with `n/a: <reason>`. End with the Reply, in the frame from `references/evidence.md`.

| Playbook | For |
|---|---|
| [extract-site](extract-site.md) | One live site's visual system into tokens and a profile |
| [extract-codebase](extract-codebase.md) | The same, from source, plus what the code says about structure |
| [survey](survey.md) | How a whole category designs itself |
| [teardown](teardown.md) | How one product is organized: shell, screens, flows, states |
| [compare](compare.md) | Two systems side by side: a redesign against its original, yours against a competitor |
| [handoff](handoff.md) | Packaging any of the above for `ui-ux-studio` |
