### Compare two systems

**You own the difference, axis by axis, with neither side described more generously.**

1. State what is being compared and why: a redesign against its original, a product against one competitor, two themes, before and after a migration.
2. Run **extract-site** or **extract-codebase** on both, at the same coverage and the same widths.
3. If structure is in question, run **teardown** on both.
4. Lay the two side by side on every axis: palette and ramps, type roles and scale, spacing, radius, elevation, motion, density, shell, state coverage, voice.
5. Mark each axis same, drifted, or deliberately different, and give the evidence for each mark.
6. Run `contrast.py` on both. A redesign that lost contrast is a finding whatever else it gained.
7. Name what was lost. Comparisons list what the new thing added and forget what the old thing did.

**Reply:** the purpose, the axis table with marks and evidence labels, what was gained, what was lost, contrast for both, and which differences look accidental.
