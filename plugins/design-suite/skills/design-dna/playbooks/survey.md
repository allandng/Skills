### Survey a category

**You own the map: what is convention, what is herd behavior, and what nobody has claimed.**

1. State the category and the subject's archetype. A survey of the wrong peers answers the wrong question.
2. Assemble six to eight: two or three direct competitors, one or two leaders, two from adjacent categories, one outlier (`references/peer-research.md`). Say why each is in the set.
3. Run **extract-site** on each, at the same coverage: the same template types from every peer.
4. For an app category, run the **teardown** walk's first six steps on each as well. Shell and state conventions are as contestable as palettes.
5. Build the comparison table.
6. Answer the four questions in writing, with counts: what is unanimous, what is contested, who is memorable and on which axis, what nobody does.
7. Sort into `CONVENTION`, `HERD`, `CONTESTED`, `UNOCCUPIED`. For each convention, name what breaking it would cost the user. If nothing, it is herd.
8. Prove it: `dna_check.py` per peer, and the date each was captured.

**Reply:** the set and why, the table, the four answers with counts ("6 of 8", never "most"), the four lists, and which lines feed `ui-ux-studio`'s remix or create.
