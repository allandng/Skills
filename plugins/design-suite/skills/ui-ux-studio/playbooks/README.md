# Playbooks

One file per job. Each is a short list of steps with an owner sentence at the top and a **Reply** line at the bottom.

How to run one:

1. Match the request to a playbook (`../references/help.md` when it is not obvious).
2. Copy its steps into your todo list, or keep the list in your reply when there is no todo tool. Copy them as written.
3. Work them in order. A step that does not apply keeps its line with `n/a: <reason>`.
4. End with the playbook's Reply, in the frame from `../references/proof.md`.

Paths in the steps are relative to the skill folder. The steps say what to do and which reference holds the detail. They do not repeat the references. `SKILL.md` and `../references/modes.md` stay the authority for the six modes. The playbook is the order of work.
