### Critique

**You own the verdict. Reviewers find. You verify. Nobody fixes.**

1. State the intent in one or two sentences, from the user's words and the design's own plan. Ask if it is unclear.
2. Pick four to six lenses (`references/critique-panel.md`). First-timer, daily user and access are always in.
3. Give each reviewer the artifact, the intent and its lens. Nothing else. Subagents in parallel when available, otherwise one lens at a time with each list written down before the next.
4. Verify every finding by going to where it points. Keep it when the evidence shows the problem and the problem breaks the intent.
5. Merge by root cause. Count the dropped ones per lens.
6. Report. Do not apply fixes.

**Reply:** `INTENT`, `FINDINGS` (title, where, evidence, how it breaks the intent, which lenses), `DROPPED` (count and reason per lens). "No verified findings" is a valid result.
