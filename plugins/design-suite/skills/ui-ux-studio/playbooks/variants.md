### Variants

**You own three treatments of one answer. The concept is settled. Only the surface moves.**

1. Confirm this is variants and not remix: the user likes one design and wants more like it (`SKILL.md`, "remix or variants?").
2. Fix the invariants: concept, layout system, signature, content (`references/modes.md`, variants Step 1).
3. Fill the variation matrix: which surface axes move in each variant, and by how much.
4. Check quality parity before building: each variant gets real ramps, a real scale, its own contrast pass. No variant is the "safe" one.
5. Build all three behind one switcher.
6. Proof ladder on each (`references/proof.md`).
