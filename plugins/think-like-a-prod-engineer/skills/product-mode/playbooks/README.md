# Playbooks

One file per job. Each is a short list of steps with an owner sentence at the top and a **Reply** line at the bottom. Paths in the steps are relative to the skill folder. Names in backticks followed by "skill" are the other skills in this plugin.

Copy the matching playbook's steps into your todo list as written, or keep the list in your reply when there is no todo tool. Work them in order. A step that does not apply keeps its line with `n/a: <reason>`. End with the Reply, in the frame from `references/proof.md`.
